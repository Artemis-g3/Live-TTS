# 数据格式说明

所有用户数据保存在项目目录下的本地文件夹中（`.gitignore` 已排除，不入库）：

```text
input_audio/          # 输入素材（用户自行放置）
workspace/            # 角色工作区（软件生成）
voice_gui_runtime/    # GUI 运行期预览状态（软件生成）
voice_gui_settings.json  # 本地配置（含 API Key）
```

---

## 一、配置文件

### `voice_gui_settings.json`

由 `GUI/config.py` 的 `AppConfig` 管理，字段与 `voice_gui_settings.example.json` 一致：

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| `voice_python` | `""` | 后端子进程 Python 路径 |
| `runtime_environment` | `""` | 运行环境标识 |
| `voxcpm2_model_path` | `VoxCPM2` | 本地模型目录 |
| `dashscope_api_key` | `""` | Qwen API Key |
| `deepseek_api_key` | `""` | DeepSeek API Key |
| `last_backend` | `voxcpm2_local_hifi` | 上次使用的合成后端 |
| `reference_window` | `10` | 检索参考音频数量 |
| `reference_min_seconds` | `15.0` | 参考音频累计时长上限（秒） |
| `gap_ms` | `300` | 参考音频拼接间隔（毫秒） |
| `voxcpm2_diffusion_steps` | `20` | VoxCPM2 扩散轮数 |
| `voxcpm2_cfg_value` | `2.0` | VoxCPM2 cfg |
| `asr_model` / `emotion_model` / `retrieval_rerank_model` / `retrieval_text_model` / `voice_enrollment_model` / `tts_target_model` | 见 README | 各阶段模型 |
| `synthesis_language` / `asr_source_language` | `zh` | 合成语言 / ASR 原始语言 |

未填写的 Key 会回退读取环境变量 `DASHSCOPE_API_KEY` / `DEEPSEEK_API_KEY`。

## 三、`audio_manifest.csv`

音频清单，由 `common/audio_manifest.py` 读写，UTF-8 with BOM：

| 字段 | 说明 |
| --- | --- |
| `role` | 角色名（已归一化） |
| `file_name` | 原始文件名 |
| `stored_name` | 存储名（`原名_sha256前10位.ext`） |
| `audio_path` | 相对项目根目录的音频路径 |
| `duration_seconds` | 时长（秒） |
| `sample_rate` | 采样率 |
| `sha256` | 文件哈希（去重主键） |
| `selected_reference` | 是否参考音频（true/false） |
| `filter_status` | `unprocessed / confirmed / review / reject / excluded / deleted` |
| `centroid_score` / `max_ref_score` / `median_ref_score` | CAM++ 筛选分数 |
| `source` | 来源标签（`input_scan` / `legacy_raw` / `legacy_confirmed` / `legacy_excel_import` 等） |
| `created_at` / `updated_at` | ISO 时间戳 |

角色目录按需自动创建：`audio/raw`、`metadata`、`library`、`output`。

---

## 四、`workflow_db.csv`

统一工作流主表，由 `common/workflow_db.py` 读写，是筛选之后所有阶段的唯一事实来源。字段分组：

**基础（来自清单）**：`role`、`sha256`、`file_name`、`stored_name`、`audio_path`、`duration_seconds`、`sample_rate`、`source`、`filter_status`、`selected_reference`、`manifest_created_at`、`manifest_updated_at`、`db_created_at`、`db_updated_at`

**ASR**：`asr_status`（done/error/空）、`asr_model`、`asr_language`、`asr_original_text`（原始文本）、`asr_transcript`（中文文本）、`asr_error`、`asr_updated_at`

**翻译**：`translation_status`、`translation_model`（`direct_copy` 表示中文直用）、`translation_error`、`translation_updated_at`

**情感**：`emotion_status`、`emotion_model`、`emotion_description`（自然语言描述）、`emotion_tone`（情绪语气）、`emotion_delivery`（音频表达技巧）、`emotion_error`、`emotion_updated_at`

**角色库**：`library_description`、`library_keywords`（情绪语气 + 音频表达技巧以中文逗号拼接）、`library_updated_at`

> 中文列名（索引、语音文件、语音文本、音频路径等）仅在 GUI 展示层使用，CSV 内部统一英文列名。

---

## 五、`emotion_runs/` 运行记录

每次情感标定在 `metadata/emotion_runs/` 生成两类文件：

- `<阶段>_<时间戳>.jsonl`：逐条记录，含角色、音频路径、原文、输入/输出、解析后 JSON、错误、预览行。
- `<阶段>_summary_<时间戳>.json`：汇总，含模型、prompt 路径、处理数量、错误数、token 用量。

阶段前缀：`emotion_run`（两步完整版）、`emotion_desc`（仅描述）、`emotion_kw`（仅关键词）。

### `tts_runs/<时间戳>/` 规范输出目录

必须包含：

```text
run_summary.json          # 运行摘要
retrieval_result.json     # 检索结果副本
reference_audio_<时间戳>.wav
reference_text_<时间戳>.txt
synthesized_<时间戳>.wav | .mp3
```

可选：

```text
style_audio_<时间戳>.wav / style_text_<时间戳>.txt   # hifi 风格音频
tts_response_<时间戳>.json                          # 云端 TTS 原始响应
voice_enrollment_response_<时间戳>.json             # 云端复刻原始响应
```

`run_summary.json` 关键字段：`role`、`backend`、`synthesis_language`、`input_transcript`、`retrieval_voice_guidance`、`synthesis_voice_guidance`、`reference_audio_path`、`reference_text_path`、`reference_duration_seconds`、`synthesized_audio_path`、`voice`、`voice_cache_fingerprint`、`used_cached_voice`、`voxcpm2_prompt_fingerprint`、`used_cached_voxcpm2_prompt`、`selected_reference_results`、`style_selected_results`。

`output_overview.py` 会校验目录规范性（必需文件唯一、可选前缀 ≤1、无多余文件），不合规目录可用 `cleanup-tts-runs` 清理或用 `normalize-tts-run-filenames` 统一命名。

## 七、缓存文件

### `voice_cache.json`

```json
{
  "fingerprints": {
    "<sha256指纹>": {
      "voice": "vc_xxxxxxxxxx",
      "preferred_name": "...",
      "target_model": "qwen3-tts-vc-2026-01-22",
      "voice_enrollment_model": "qwen-voice-enrollment",
      "language": "zh",
      "created_at": "2026-05-30T17:52:04"
    }
  }
}
```

指纹 = sha256(参考音频字节 + 参考文本 + 目标模型 + 语言)。

### `voxcpm2_prompt_cache.json` 与 `voxcpm2_prompt_cache/`

指纹 = sha256(参考音频 + 参考文本 + 模型路径 + 模式 + [风格音频 + 风格文本])；`*.pt` 为 VoxCPM2 的 prompt cache 张量，避免每次合成重复构建。

### `input_scan_cache.json`

版本化增量扫描缓存，按 `路径 → {size, mtime_ns, row}` 记录，供 `input_audio.py` 判断新增/变更文件。
