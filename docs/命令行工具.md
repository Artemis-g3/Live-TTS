# 命令行工具参考

后端全部能力集中在 `GUI/backend/workflow_cli.py`，GUI 即通过它执行任务。命令格式：

```powershell
python GUI\backend\workflow_cli.py <子命令> [参数]
```

查看帮助：

```powershell
python GUI\backend\workflow_cli.py --help
python GUI\backend\workflow_cli.py tts --help
```

## 输出协议

每条命令结束时向 stdout 输出一行结构化结果：

```text
VOICE_GUI_RESULT_JSON={"success": true, "message": "...", "output_paths": {...}, "data": {...}}
```

运行过程中的进度、token 用量等为普通日志行（不带前缀）。脚本化调用时可过滤 `VOICE_GUI_RESULT_JSON=` 前缀并解析 JSON。

退出码：成功 0，失败 1。

## 角色参数

大部分命令需要 `--role`。角色名会做别名归一化：

```text
moning / morning / m / 1  → 莫宁
yuno / younuo / y / 2     → 尤诺
```

## 状态与迁移

### `state`

扫描项目状态（角色列表、各阶段音频/ASR/情感/输出统计）。

### `migrate-workspace`

将旧版目录结构迁移到 `workspace/`：

```text
1.原始音频 / 1.参考音频 / 1.筛选音频 / 2.语音识别 / 4.整理音频 / 5.双层情感检索配音-pro
```

### `import-role-from-excel`

从历史 Excel 角色库导入音频与标注（不运行筛选/ASR/情感，直接写历史结果）：

```powershell
python GUI\backend\workflow_cli.py import-role-from-excel --role 莫宁 --audio-dir <音频目录> --excel <角色库.xlsx>
```

Excel 必需列：`索引 / 语音文件 / 语音文本 / 自然语言描述 / 情绪语气 / 音频表达技巧`。

### `sync-workflow-db`

将 `audio_manifest.csv` 基础字段同步进 `workflow_db.csv`（幂等，无变化不重写）。

## 筛选

```powershell
# 运行 CAM++ 说话人筛选（需要先保存 ≥2 条参考音频）
python GUI\backend\workflow_cli.py filter-audio --role 莫宁 --confirm-threshold 0.72 --review-threshold 0.60

# 更新指定音频状态（confirmed/review/reject/excluded/deleted/unprocessed）
python GUI\backend\workflow_cli.py update-filter-status --role 莫宁 --status confirmed --input-json <sha256数组.json>

# 标记/保存参考音频
python GUI\backend\workflow_cli.py save-reference-selection --role 莫宁 --input-json <sha256数组.json>

# 保存筛选结果（input-json 为筛选预览行数组）
python GUI\backend\workflow_cli.py save-filter-results --role 莫宁 --input-json <筛选行.json>
```

## ASR 与翻译

```powershell
# 全量 ASR（zh/en/ja）
python GUI\backend\workflow_cli.py run-asr --role 莫宁 --language zh

# 单条 ASR（--sha256 + --force 可重跑）
python GUI\backend\workflow_cli.py run-asr --role 莫宁 --language en --sha256 <sha256> --force

# 翻译（非中文 → 简体中文）
python GUI\backend\workflow_cli.py run-translation --role 莫宁 --input-json <asr预览行.json> --language en

# 保存 ASR/翻译结果
python GUI\backend\workflow_cli.py save-asr --role 莫宁 --input-json <asr预览行.json>
```

`--limit N` 可限制处理条数；`--model` 可覆盖 ASR 模型。

## 情感标定

```powershell
# 两步完整版：多模态描述 + 文本模型关键词
python GUI\backend\workflow_cli.py run-emotion --role 莫宁 --text-model qwen3.6-flash

# 只做情感描述
python GUI\backend\workflow_cli.py run-emotion-description --role 莫宁

# 只做关键词提取（需要已有描述）
python GUI\backend\workflow_cli.py run-emotion-keywords --role 莫宁 --text-model qwen3.6-flash

# 保存
python GUI\backend\workflow_cli.py save-emotion --role 莫宁 --input-json <情感预览行.json>
```

单条处理同样用 `--sha256`；`--force` 强制重跑。运行记录写入 `metadata/emotion_runs/`。

## 检索

```powershell
python GUI\backend\workflow_cli.py retrieve --role 莫宁 `
  --transcript-text "你要合成的台词" `
  --voice-description "温柔、略带无奈" `
  --reference-window 10
```

输出：`output/tts_retrieval_cache/<时间戳>/retrieval_result.json`，包含 `top_results`（排名、音频路径、描述、关键词、分数）。

## 合成（TTS）

### 一键流程：检索 + 合成

```powershell
python GUI\backend\workflow_cli.py tts --role 莫宁 `
  --transcript-text "台词" `
  --voice-description "温柔、略带无奈" `
  --backend api
```

`--backend` 可选：

| 值 | 说明 |
| --- | --- |
| `api` | 云端声音复刻 + qwen3-tts-vc |
| `voxcpm2_local_basic` | 本地 VoxCPM2 basic 克隆 |
| `voxcpm2_local_hifi` | 本地 VoxCPM2 hifi 克隆（原文 + 风格音频） |

常用参数：

```text
--synthesis-language zh|en|ja
--reference-window 10            # 参考音频候选数
--reference-min-seconds 15.0     # 参考音频累计上限
--gap-ms 300                     # 参考音频拼接静音
--voxcpm2-diffusion-steps 20
--voxcpm2-cfg-value 2.0
--synthesis-guidance "声音指导"   # 仅 basic 生效
--selected-results-json <文件>    # 指定勾选的参考音频行
--style-results-json <文件>       # 指定风格音频行（hifi）
--play                           # 合成后自动播放
```

### 分步流程：先检索、后合成

```powershell
python GUI\backend\workflow_cli.py retrieve --role 莫宁 --transcript-text "..." --voice-description "..."

python GUI\backend\workflow_cli.py synthesize --role 莫宁 `
  --transcript-text "..." `
  --voice-description "..." `
  --backend voxcpm2_local_hifi `
  --retrieval-result-path <retrieval_result.json 绝对路径> `
  --session-dir <检索缓存会话目录>
```

`synthesize` 会在 `output/tts_runs/` 生成新的规范输出目录。

## 脚本化示例

PowerShell 中解析结果：

```powershell
$out = python GUI\backend\workflow_cli.py state
$resultLine = $out | Where-Object { $_ -like "VOICE_GUI_RESULT_JSON=*" }
$json = ($resultLine -replace "^VOICE_GUI_RESULT_JSON=", "") | ConvertFrom-Json
$json.data.roles | Format-Table role, input_audio_count, confirmed_audio_count
```
