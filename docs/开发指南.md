## 代码组织约定

### 分层原则

1. **后端模块（`code/voice_modules/`）不依赖 GUI**，只依赖 `GUI/config.py` 中的 `PROJECT_ROOT` 路径常量（跨层最小耦合，可后续抽离）。
2. **GUI 不直接调用模型**：通过 `QProcess` 执行 `workflow_cli.py` 子命令，用 `VOICE_GUI_RESULT_JSON=` 前缀协议取回结果。
3. **新增功能优先走后端模块 + CLI 子命令**，再在 `main_window.py` 加按钮/页签接入。
4. 数据写入统一走 `common/audio_manifest.py` / `common/workflow_db.py`，避免各模块各自造表。

### 新增一个处理阶段（参考现有 ASR 模块）

1. 在 `code/voice_modules/` 下新建 `my_stage/` 包，提供：
   - `run_xxx(role, ...)`：执行处理，返回预览行数组；
   - `load_xxx_rows(role)`：从 `workflow_db.csv` 读取；
   - `save_xxx_rows(role, rows)`：写回 `workflow_db.csv`。
2. 在 `workflow_db.py` 的 `WORKFLOW_DB_FIELDS` 中追加字段（一次性扩展所有角色主表）。
3. 在 `workflow_cli.py` 注册 `run-my-stage` / `save-my-stage` 子命令。
4. 在 `main_window.py` 增加页签或按钮，复刻 ASR 页的 QProcess 处理模式（`start_process` / `extract_result` / `handle_*_result`）。

### 模型调用约定

- 文本类任务统一走 OpenAI 兼容协议（`dubbing/retrieval.py` 的 `make_openai_client`），Qwen 与 Deepseek 按模型名前缀自动路由。
- 多模态音频输入统一转 `data:` URL。
- 所有云端调用都记录 token 用量到日志，方便核算成本。
- 可缓存的重活（声音复刻、VoxCPM2 prompt）必须加指纹缓存，见 `tts.py`。

## 目录与文件命名约定

- 源码统一 UTF-8；CSV 输出使用 UTF-8 with BOM（`utf-8-sig`），保证 Excel 直接打开不乱码。
- 运行产物目录用时间戳 `%Y%m%d_%H%M%S`，冲突时追加 `_01` 后缀。
- 输出目录遵循 `output_overview.py` 的规范命名（`synthesized_<时间戳>.wav` 等），新增产物文件需同步更新 `_is_conforming_run_dir` 白名单。

> ⚠️ **避免非 ASCII 文件名**：`dubbing/prompts/prompt-最终排序.txt` 这类中文文件名在部分 Git 环境会出现乱码（云端仓库中已出现 `prompt-????.txt`）。建议重命名为 ASCII（如 `final_ranking_prompt.txt`），并同步更新 `retrieval.py` 中的 `DEFAULT_FINAL_RANKING_PROMPT_PATH`。


### 嵌套 Git 仓库

### CAM++ 说话人验证模型目录

`code/voice_modules/audio_filter/speech_campplus_sv_zh-cn_16k-common/` 是说话人筛选使用的第三方模型（CAM++，Apache-2.0），**不随仓库提交**，已加入 `.gitignore`。首次使用请运行：

```powershell
python scripts\download_campplus.py
```

脚本会从 ModelScope 下载模型（约 28MB）到该目录。

### 提交规范

- 提交信息用中文或英文均可，保持简洁，如 `docs: 重写 README 与文档`、`feat: 新增长文本分句模块`。
- 大文件（模型权重、音频素材、exe）一律不入库；如需分发模型请走 ModelScope / HuggingFace。
- 提交前运行 `python GUI\main.py --smoke-test` 确保 GUI 可启动。

## 打包

```powershell
pip install pyinstaller
python -m PyInstaller --noconfirm --clean --distpath . --workpath build\pyinstaller build\VoiceDubbingGUI.spec
```

要点：

- spec 已包含 `pathex`（项目根 + `code/`）与 `hiddenimports=['PyQt6.QtMultimedia']`。
- exe 是 GUI 壳，运行仍需要项目目录下的 `code/`、`VoxCPM2/`（如用本地 TTS）、CAM++ 模型目录（需先运行 `scripts/download_campplus.py`）。
- 后端以子进程调用，发布时需确保目标机器安装对应 Python 环境与依赖（`voice_python` / 运行环境设置）。

## 调试技巧

- **只跑后端**：直接用 `python GUI\backend\workflow_cli.py <子命令>`，观察 stdout 日志与结果 JSON，不依赖 GUI。
- **查看协议**：GUI 日志区展示子进程输出；后端错误会带 traceback 打印，随后输出 `success:false` 结果。
- **预览与保存分离**：表格中的结果未保存前不会写入主表，排查问题时可先跑「预览」再决定保存。
- **清理运行记录**：`metadata/emotion_runs/`、`output/tts_retrieval_cache/` 可安全删除；`workspace/trash/` 可手动清理。
