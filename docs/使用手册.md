# 使用手册

本文档按 GUI 页签顺序介绍「配音软件」的完整操作方式。启动方式：

```powershell
python GUI\main.py
```

窗口底部为全局音频播放器，可播放任意表格中选中的音频；每个任务页签下方都有独立的运行日志区。

---

## 0. 设置页

首次使用先完成配置：

| 配置项 | 说明 |
| --- | --- |
| VoxCPM2 模型目录 | 本地 TTS 模型路径，默认 `VoxCPM2` |
| 运行环境 | 后端子进程使用的 Python 环境（自动扫描 conda/venv），也可手动「选择」 |
| Qwen API Key | DashScope 密钥，ASR / 情感 / 检索 / 云端 TTS 均需要 |
| Deepseek API Key | 使用 Deepseek 排序/分句模型时需要 |
| 各模型下拉框 | ASR、音频描述、检索排序、文本、声音复刻、云端合成模型 |

点击「保存设置」后写入 `voice_gui_settings.json`（不入库）。未填写 API Key 时也会读取同名环境变量。

---

## 1. 输入音频概览

功能：把 `input_audio/<角色>/` 下的音频素材扫描进角色工作区。

1. 将音频放入 `input_audio/<角色名>/`（支持 wav / mp3 / m4a / flac / ogg，可含子目录）。
2. 选择角色，点击「同步输入文件夹」。
3. 表格列出音频清单：时长、采样率、筛选状态、是否参考音频等。
4. **勾选 2 条以上目标角色的参考音频，点击「保存参考」**（后续筛选与检索依赖参考音频）。
5. 「统计时长分布」查看 0-2s / 2-5s / 5-10s / 10-15s / 15-30s / 30s+ 分布。

右键选中行可移入回收区（文件移动到 `workspace/trash/`）。

---

## 2. 音频筛选

基于 CAM++ 声纹模型，将候选音频与参考音频的质心比较：

- `strong = min(质心相似度, 最高参考相似度)`，达到 confirm 阈值 → confirmed
- `soft = min(最高参考相似度, max(质心, 中位参考))`，达到 review 阈值 → review
- 否则 → reject（不保存，仅展示）

操作：

1. 点击「加载音频筛选」。
2. 设置 confirm / review 阈值（默认 0.72 / 0.60，review 必须小于 confirm）。
3. 点击「运行筛选」，等待完成。
4. 在 Confirm / Review 两个表中核对，可用「移到 Review」「加入 Confirm」「移出」人工调整。
5. 点击「保存结果」写入 `audio_manifest.csv`。

后续 ASR 只处理 `confirmed` 状态的音频。

---

## 3. 语音识别

ASR 使用 Qwen3-ASR-Flash，支持原始语言 `zh / en / ja`：

- 中文音频：识别结果直接作为中文文本；
- 非中文音频：识别出原文后，需要再运行「翻译」得到简体中文。

操作：

1. 选择角色与原始语言。
2. 「全量 ASR」：对全部 confirmed 音频执行识别；「单条 ASR」只处理选中行。
3. 非中文时点击「全量翻译」（或「单条翻译」）。
4. 表格可手动编辑文本，确认无误后「全部保存」写入 `workflow_db.csv`。

> 未保存前结果仅存在于表格预览中；运行日志会显示进度与 API token 用量。

---

## 4. 情感标定

分两步，第一步生成自然语言描述，第二步抽取关键词：

1. **全量情感描述**（单模态可多选）：Qwen3.5-Omni 聆听音频 + 对应文本，生成 50-150 字“导演式”语音描述。
2. **全量提取关键词**：文本模型从描述中抽取两类关键词：
   - 情绪语气 / 表达态度（如：轻松打趣、无奈、郑重）
   - 音频表达技巧（如：语速放缓、尾音拖长、句尾下沉）
3. 核对表格内容后可手动修改，「保存情感标定」写入 `workflow_db.csv`。

每次运行会在 `workspace/roles/<角色>/metadata/emotion_runs/` 留下 JSONL 运行记录与摘要（含输入输出与 token 用量）。

## 5. 配音工作台

核心合成页面，流程为：**检索参考音频 → 选择参考 → 合成配音**。

### 5.1 输入

| 输入项 | 说明 |
| --- | --- |
| 角色 | 目标角色（对应 workspace 角色目录） |
| 合成后端 | `api`（云端）/ `voxcpm2_local_basic` / `voxcpm2_local_hifi` |
| 合成语言 | 中文 / 英语 / 日语 |
| 配音台词 | 要合成的目标文本 |
| 检索声音指导 | 描述希望的声音/情绪（如“温柔略带无奈”） |
| 合成声音指导 | 仅对 VoxCPM2 Basic 生效，以括号形式注入文本 |
| 第二轮音频数量 | 检索 top_k（默认 10） |
| 扩散轮数 / 模仿相似度 | VoxCPM2 参数（inference_timesteps / cfg_value） |

「自动指导」按钮：输入台词后一键生成检索声音指导关键词（由文本模型分析台词情感）。

### 5.2 检索

点击「开始检索」，执行双层检索：

1. `qwen3-rerank` 按“情绪语气 + 表达技巧关键词”粗排；
2. 文本模型对候选描述 + 关键词做最终排序；

结果表格展示排名、音频、时长、描述与关键词。检索结果同时缓存到 `output/tts_retrieval_cache/<时间戳>/`。

### 5.3 合成

在检索结果中勾选需要的参考音频（不勾选则取前 N 条），点击「开始合成」：

- **api 后端**：先用参考音频 + 文本做声音复刻（`qwen-voice-enrollment`，结果按指纹缓存），再调用 `qwen3-tts-vc` 合成，下载音频到输出目录。
- **VoxCPM2 Basic**：参考音频做 basic 克隆；若填了合成声音指导，会以 `(指导)文本` 形式注入。
- **VoxCPM2 HiFi**：参考音频 + 原文 + 可选的风格音频做 hifi 克隆（prompt cache 按指纹缓存到 `output/voxcpm2_prompt_cache/`）。

合成完成自动生成规范输出目录（见下节），日志区会输出所有产物路径与 token 用量。

---

## 6. 长文本配音

用于数百字以上的长文本：

1. 粘贴文本到输入框。
2. 可选「启用思考模式」（Deepseek 对应 thinking、Qwen 对应 enable_thinking）。
3. 点击「自动分句描述」：LLM 按情感/语气变化切分为 15-60 字的短句，并为每句生成 2-5 个声音表现关键词。
4. 在结果表中**双击某一句**，自动跳转到配音工作台并填入该句与声音指导。
5. 逐句检索、合成，完成整段配音。

---

## 7. 输出概览

列出角色所有规范的 TTS 输出（`output/tts_runs/<时间戳>/`），每行含：

- 语音名称（合成音频文件名）
- 配音台词
- 检索声音指导文本
- 合成声音指导文本（仅 VoxCPM2 Basic 显示）

操作：

- 双击/选中行播放合成音频；
- 「打开输出文件夹」定位到角色输出目录；
- 「删除选中」删除对应 tts_runs 目录；
- 「清理非规范目录」「统一文件命名」用于维护旧版本遗留的输出。

每次合成的目录结构：

```text
output/tts_runs/20260530_175204/
├── run_summary.json          # 运行摘要（台词、指导、路径、指纹、token）
├── retrieval_result.json     # 本次使用的检索结果
├── reference_audio_*.wav     # 拼接的参考音频
├── reference_text_*.txt      # 参考音频对应文本
├── style_audio_*.wav         # （可选）风格音频
├── style_text_*.txt          # （可选）风格文本
├── synthesized_*.wav/mp3     # 最终合成音频
└── tts_response.json / voice_enrollment_response.json   # （云端后端）API 响应
```

## 8. 命令行方式

所有页面功能都对应 `workflow_cli.py` 子命令，可脱离 GUI 使用：

```powershell
python GUI\backend\workflow_cli.py sync-input-audio --role 莫宁
python GUI\backend\workflow_cli.py run-asr --role 莫宁 --language zh
python GUI\backend\workflow_cli.py tts --role 莫宁 --transcript-text "..." --voice-description "..." --backend api
```

详见 [命令行工具.md](命令行工具.md)。
